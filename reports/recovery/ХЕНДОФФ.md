## Главная находка: поломка шире, чем считалось

В прошлой сессии было установлено, что **российский origin не проталкивает в
Cloudflare ничего крупнее ~24 КБ**. Тогда думали, что это касается только 20
восстановленных доноров на московском сервере.

**Это касается всей сети.** Замерено 03.09 в живом браузере на донорах, которые
всё это время считались здоровыми (Timeweb, другой хостинг, другая сеть):

| донор | картинок на главной | битых |
|---|---|---|
| `sibertek.ru` | 12 | **10** |
| `photoset-msk.ru` | 11 | **10** |

Ключевой замер — `fetch` обложки на `sibertek.ru` прямо со страницы:
`status=200`, `cf-cache-status: MISS`, **40.5 секунды, тело так и не пришло**.
Тот же обрыв, что на московской машине. Два разных хостинга, одна поломка.

### Направление сузилось

**Исходящее из России в целом исправно.** Московский сервер отдал 20 МБ по SSH
на машину за пределами РФ на полной скорости, без обрывов. Значит формулировка
«из России не уходит крупное» неверна — ломается конкретно путь
**российский origin → Cloudflare по 443**.

**Решающий замер не сделан.** Чтобы отличить «затык именно к Cloudflare» от
«затык на 443 куда угодно», нужно на минуту впустить немецкий IP в nftables
московского сервера (там стоит замок origin, пускающий только Cloudflare).
Команда заблокирована классификатором — **нужно разрешение пользователя**.
От результата зависит, останется origin в России или нет.

## Ловушки — не наступать снова

**Токен из `.env` ведёт не туда.** `CLOUDFLARE_API_TOKEN` видит 18 зон, включая
все 16 наших доменов по именам, — но все они `status=initializing` в аккаунте
`Chechetov.alex@gmail.com` (CF-1). Это неделегированные дубли. Правки через них
возвращают `success: true` и **не меняют ничего в интернете**: живая зона
`avtogear62.ru` лежит в аккаунте `manuel.farley@4pbn.com` с NS `bethany`/`kyrie`,
а дубль предлагает `art`/`tiffany`, куда никто не смотрит.

**Перед любой правкой проверять `status=active`.** И имеет смысл снести 17
неделегированных дублей из CF-1, оставив только `стандарт72.рф`, который ждёт
делегирования по делу.

**Один токен на всю сетку невозможен в принципе.** Токен Cloudflare живёт внутри
одного аккаунта. У каждого донора свой аккаунт — это и есть механизм
анти-аффилиации. Один токен на 16 доменов означал бы 16 доменов в одном аккаунте.

**`/user/tokens/verify` врёт про аккаунтные токены** — отвечает `Invalid API
Token` на совершенно рабочий токен. Проверять надо запросом `/zones`.

**`curl` без `--compressed` врёт.** Порог считается по байтам в канале: сжатая
страница 15–18 КБ проходит, несжатая 73 КБ — нет. Браузеры и краулеры сжатие
просят всегда.

**Скриншот темы Blocksy врёт.** Контейнер `boundless-image` снимается белым
прямоугольником, хотя картинка на месте. Проверять через canvas: у
`avtogear62.ru` средний цвет 89,93,101 при диапазоне 2–252 — содержимое есть.

**Внешние проверки бесполезны.** 47 из 49 доменов отдают снаружи 403 (челлендж).
Мерить можно только с IP из белого списка правила Search Protection либо
настоящим браузером, который челлендж проходит.

## Проверено и опровергнуто — не искать заново

Причиной обрыва **не являются**: размер сегмента (MSS 1360/1000/700), MTU
(потерь 0%), HTTP/2 на origin, сжатие как таковое, кеш Cloudflare (промахи
виснут так же), `sendfile` (с `off` только хуже), заголовки origin, настройки
зоны (Workers, Origin Rules, Transform Rules отсутствуют), список адресов
Cloudflare в замке origin, conntrack. Симптом воспроизводится на доменах из
разных аккаунтов Cloudflare и на двух разных хостингах — значит не в зоне и не
в конкретной машине.

Прочее, остающееся верным:

- **`wp import` сохраняет исходные post_id**, если те свободны.
- **Слаг = транслитерация заголовка** (Cyr-To-Lat: `я→ja`, `щ→shh`, `х→h`).
- **У каждого домена свой аккаунт Cloudflare и своя пара NS.** Переезд — правка
  A-записи, регистратор не участвует.
- **SSL ставить `Full`, не `Full (Strict)`** — origin с самоподписанным сертификатом.
- **Правило Search Protection** даёт Managed Challenge всем, кроме поисковых
  ботов по ASN (15169 Google, 396982 Google Cloud, 13238 Яндекс, 208722 Nebius,
  212066 Buyuk Reklam) и своих IP. Держит анти-аффилиацию — **ослаблять нельзя**.
  Белый список только по IPv4, проверки снаружи гонять с `curl -4`.
- **Почта `4pbn.com` жива:** MX → `mail.4pbn.com` → 194.87.68.176 (Beget).
- Метрики Hetzner по сети читать осторожно.
- Поисковики ходят: за сутки на московском origin YandexBot 145, Googlebot 67,
  ответы 189×200 / 52×404 / 32×301. Запросов картинок — **ноль**.
